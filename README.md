# 📊 Sales Forecast & Demand Prediction Analysis

An interactive **Power BI dashboard** for analyzing sales performance, demand forecasting, inventory levels, seasonality, and forecast accuracy.

## 🎯 Key Features

- 📈 Monthly Sales Trend
- 🔮 Actual vs Forecast Demand
- 🏆 Top 10 Product Performance
- 🛍️ Sales by Category
- 🌦️ Seasonal Demand Analysis
- 📦 Inventory vs Demand
- ⚠️ Stockout Event Tracking
- 🎯 Forecast Error Analysis

## 🎛️ Interactive Filters

- Date
- Region
- Seasonality
- Store ID
- Weather Condition
- Category

## 📌 Key KPIs

- Total Sales
- Total Units Sold
- Forecast Demand
- Stockout Events
- Average Forecast Error

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Modeling

## 💡 Business Objective

The dashboard helps businesses understand sales and demand patterns, monitor inventory, evaluate forecast accuracy, and make better data-driven decisions.
